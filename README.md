# Community Science Museum - Science Museum Website
Community Science Museum is a fictional science museum website created as part of Semester Project 1 at Noroff. The project explored how HTML and CSS can be used to build an informative, accessible, and responsive website for a museum.

## Description
The purpose of this project was to develop a website that introduces visitors to a science museum and makes essential visitor information easy to find. The design combines exhibition content with practical details to help users learn about the museum and plan their visit.

The website was developed individually, using semantic HTML and CSS to create a consistent layout across different screen sizes.

## Pages
The project consists of six pages:
- Home: An overview of the museum with links to key sections of the website.
- Explore: Provides an introduction tothe museum's activities and opportunities for discovery.
- Exhibitions: Introduces topics such as cosmology, evolution, and ecology.
- Events: Presents different special events at the museum, with dates.
- Visit: Presens practical visitor information, including opening hours, location, and an embedded map.
- Get involved: Provides practical information regarding volunteering or internships.

## Key Features
- Responsive layouts for mobile, tablet, and desktop screens.
- Navigation designed to make the website easy to explore.
- Consistent buttons, cards, and call-to-action sections.
- Newsletter sign up section.
- Interactive Google Maps embed.

## Built With

- HTML5 - Website structure and content
- CSS3 - Styling, layout, and responsive design
- Figma - Design planning and visual references

## Run the Project Locally

### Requirements
You will need Git, a code editor such as Visual Studio Code, and a web browser.

### Setup

1. Clone the repository:

```bash
git clone https://github.com/LinxonXD/semester-project.git
```

2. Navigate to the project directory:

```
cd semester-project
```

3. Open the folder in Visual Studio Code

4. Install or enable the Live Server Extension, then launch index.html using Open with Live Server.

5. Open the local addess provided by Live Server in your browser. The port may vary depending on your configuration.
